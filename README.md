# TikTok Clone Project

This project is a clone of TikTok, built with a modern web stack. The goal is to replicate core features of the TikTok application, focusing on video streaming, sharing, and social interaction.

## Features
- User Authentication
- Video Uploads and Streaming
- Like and Comment System
- User Profiles

## Installation

To install the project, follow these steps:
1. Clone the repository: `git clone https://github.com/uchihaabir10-droid/Aralabgami.git`
2. Navigate to the project directory.
3. Run `npm install` to install all dependencies.
4. Start the development server with `npm start`.
